NGT Academy Network Engineering & Cybersecurity Labs

This repository documents my hands-on lab work from NGT Academy's Full Stack Network Engineer and Cybersecurity training. Each project begins with a practical technical problem and records how I designed, configured, tested, troubleshot, and validated a working solution.

The goal is to demonstrate applied networking and security skills—not simply the completion of coursework. Lab entries may include network diagrams, sanitized device configurations, command output, packet captures, screenshots, troubleshooting notes, and lessons learned.

Status: This is an active learning portfolio. Projects will be added as I complete and document them.

About the Training

NGT Academy describes its program as hands-on preparation for network engineering, cybersecurity, and data-center operations. Its public curriculum emphasizes networking fundamentals, Cisco CCNA preparation, infrastructure and systems, security fundamentals, CompTIA certification preparation, red-team and blue-team exercises, and realistic technical scenarios.

This repository translates that training into evidence of practical work: identifying a requirement or fault, selecting an approach, implementing the solution, and verifying the result.

How Each Project Is Documented

Each lab will use a consistent, employer-friendly format:

Problem — The business or technical issue to solve.

Requirements — Expected behavior, constraints, and success criteria.

Environment — Topology, devices, operating systems, tools, and addressing.

Approach — The reasoning behind the design or troubleshooting plan.

Implementation — Sanitized configurations, commands, or procedures.

Validation — Tests and evidence showing that the solution works.

Troubleshooting — Problems encountered, root causes, and corrections.

Lessons learned — Skills reinforced and possible improvements.
